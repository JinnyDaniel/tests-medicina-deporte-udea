¿Cómo agregar un nuevo test a este catálogo? Cada test es una página HTML independiente (como milla.html) con el mismo patrón: valoración pre-test → PAR-Q → consentimiento informado con firma digital → hoja de registro → cálculo → descarga de PDF. Crea el archivo nuevo, agrégalo como una tarjeta más aquí en index.html, y súbelo junto con los demás. No se necesita ningún servidor ni base de datos: todo funciona dentro del navegador.
